Renderizando listas
Frequentemente, você desejará exibir vários componentes semelhantes a partir de uma coleção de dados. Você pode usar os métodos de array do JavaScript para manipular um array de dados. Nesta página, você usará filter()esses map()métodos com React para filtrar e transformar seu array de dados em um array de componentes.

Renderizando dados de matrizes
Suponha que você tenha uma lista de conteúdo.

<ul>
  <li>Creola Katherine Johnson: mathematician</li>
  <li>Mario José Molina-Pasquel Henríquez: chemist</li>
  <li>Mohammad Abdus Salam: physicist</li>
  <li>Percy Lavon Julian: chemist</li>
  <li>Subrahmanyan Chandrasekhar: astrophysicist</li>
</ul>
A única diferença entre os itens dessa lista é o conteúdo, os dados. Frequentemente, você precisará exibir várias instâncias do mesmo componente usando dados diferentes ao criar interfaces: desde listas de comentários até galerias de imagens de perfil. Nessas situações, você pode armazenar esses dados em objetos e arrays JavaScript e usar métodos como `map` map()e filter()`filter` para renderizar listas de componentes a partir deles.

Aqui está um breve exemplo de como gerar uma lista de itens a partir de um array:

Mova os dados para uma matriz:
const people = [
  'Creola Katherine Johnson: mathematician',
  'Mario José Molina-Pasquel Henríquez: chemist',
  'Mohammad Abdus Salam: physicist',
  'Percy Lavon Julian: chemist',
  'Subrahmanyan Chandrasekhar: astrophysicist'
];
Mapeie os peoplemembros em uma nova matriz de nós JSX listItems:
const listItems = people.map(person => <li>{person}</li>);
Retorne listItems do seu componente envolvido em um <ul>:
return <ul>{listItems}</ul>;
Eis o resultado:






const people = [

Observação
Elementos JSX diretamente dentro de uma map()chamada sempre precisam de chaves!

As chaves informam ao React a qual item do array cada componente corresponde, para que ele possa associá-los posteriormente. Isso se torna importante se os itens do seu array puderem ser movidos (por exemplo, devido à ordenação), inseridos ou excluídos. Uma chave bem escolhida keyajuda o React a inferir exatamente o que aconteceu e a fazer as atualizações corretas na árvore DOM.

Em vez de gerar chaves dinamicamente, você deve incluí-las em seus dados:

Onde conseguir o seukey 
Diferentes fontes de dados fornecem diferentes fontes de chaves:

Dados de um banco de dados: Se seus dados vierem de um banco de dados, você pode usar as chaves/IDs do banco de dados, que são únicas por natureza.
Dados gerados localmente: Se seus dados forem gerados e armazenados localmente (por exemplo, notas em um aplicativo de anotações), use um contador incremental crypto.randomUUID()ou um pacote como este uuidao criar itens.
Regras das chaves
As chaves devem ser únicas entre os elementos irmãos. No entanto, não há problema em usar as mesmas chaves para nós JSX em arrays diferentes .
As chaves não devem ser alteradas , caso contrário, sua função será anulada! Não as gere durante a renderização.
Por que o React precisa de chaves?
Imagine que os arquivos na sua área de trabalho não tivessem nomes. Em vez disso, você se referiria a eles pela ordem em que aparecem — o primeiro arquivo, o segundo arquivo e assim por diante. Você poderia se acostumar com isso, mas depois de excluir um arquivo, tudo ficaria confuso. O segundo arquivo se tornaria o primeiro, o terceiro arquivo se tornaria o segundo e assim por diante.

Os nomes de arquivos em uma pasta e as chaves JSX em um array têm uma função semelhante. Eles nos permitem identificar um item de forma única entre seus irmãos. Uma chave bem escolhida fornece mais informações do que a posição dentro do array. Mesmo que a posição mude devido à reordenação, ela keypermite que o React identifique o item durante todo o seu ciclo de vida.

Armadilha
Você pode ser tentado a usar o índice de um item no array como sua chave. Na verdade, é isso que o React usará se você não especificar um índice key. Mas a ordem em que os itens são renderizados mudará com o tempo se um item for inserido, excluído ou se o array for reordenado. Usar o índice como chave geralmente leva a bugs sutis e confusos.

Da mesma forma, não gere chaves dinamicamente, por exemplo, com ` key={Math.random()}. Isso fará com que as chaves nunca correspondam entre as renderizações, levando à recriação de todos os seus componentes e do DOM a cada vez. Além de ser lento, isso também perderá qualquer entrada do usuário nos itens da lista. Em vez disso, use um ID estável baseado nos dados.

Observe que seus componentes não receberão ` keyid` como uma propriedade. Ele é usado apenas como uma dica pelo próprio React. Se o seu componente precisar de um ID, você terá que passá-lo como uma propriedade separada: `id` <Profile key={id} userId={id} />.
